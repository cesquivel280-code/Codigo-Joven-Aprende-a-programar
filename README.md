Aprende a programar: JavaScript desde cero

¡Bienvenido! Este proyecto está pensado para personas que nunca programaron y quieren aprender JavaScript de una manera sencilla, práctica y paso a paso.

No necesitás ser programador ni tener experiencia previa. Vamos a aprender con ejemplos fáciles de entender, código listo para copiar y pegar y ejercicios que podés ejecutar en una consola de JavaScript.

🎯 Objetivo

Aprender los fundamentos de JavaScript y utilizarlos para crear programas y minijuegos.

📚 Lecciones para principiantes

1. ¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite dar instrucciones a una computadora. Se utiliza para realizar cálculos, mostrar mensajes, crear juegos y desarrollar aplicaciones interactivas.

2. Tu primer programa

console.log("¡Hola, mundo!");

Resultado:

¡Hola, mundo!

"console.log()" permite mostrar información en la consola.

3. ¿Qué es una variable?

Una variable es un espacio donde guardamos información, como un nombre, una puntuación o la cantidad de vidas de un jugador.

Usamos "let" cuando el valor puede cambiar.

let puntos = 0;

console.log(puntos);

puntos = 10;

console.log(puntos);

Resultado:

0
10

4. ¿Qué es "const"?

"const" permite declarar una variable que no puede recibir una nueva asignación.

const nombreJuego = "Mi primer juego";

console.log(nombreJuego);

Resultado:

Mi primer juego

5. ¿Qué es una función?

Una función es un conjunto de instrucciones que podemos ejecutar cuando lo necesitamos.

function saludar() {
  console.log("¡Bienvenido al juego!");
}

saludar();

Resultado:

¡Bienvenido al juego!

6. ¿Qué es una condición?

La instrucción "if" permite ejecutar una acción cuando se cumple una condición.

let puntos = 60;

if (puntos >= 50) {
  console.log("¡Ganaste!");
}

Resultado:

¡Ganaste!

7. Operaciones matemáticas

JavaScript permite realizar cálculos:

console.log(5 + 3);
console.log(10 - 4);
console.log(3 * 4);
console.log(12 / 3);

Resultado:

8
6
12
4

8. Comentarios en el código

Los comentarios sirven para explicar qué hace un programa. No se ejecutan como instrucciones.

// Este es mi primer comentario.

console.log("Estoy aprendiendo JavaScript");

🎮 Proyecto práctico: crear un minijuego

Cuando conozcas los conceptos básicos, vas a poder crear un minijuego con:

- Cinco preguntas.
- Tres vidas.
- Puntuación y puntos de experiencia (XP).
- Respuestas correctas e incorrectas.
- Mensajes de victoria y derrota.

🧑‍🏫 Método de aprendizaje

1. Leer la explicación.
2. Copiar el código.
3. Pegarlo en la consola de JavaScript.
4. Ejecutarlo y observar el resultado.
5. Cambiar algún valor para experimentar.
6. Resolver un pequeño ejercicio.

💡 Recomendación

No intentes memorizar todo de una sola vez. Practicá un concepto por vez y aprendé a comprender las instrucciones antes de avanzar.
